# Frontend

React + TypeScript + Vite + Tailwind + Leaflet UI for the Spotter ELD trip planner.

```bash
npm install
npm run dev    # http://127.0.0.1:5173 — proxies /api to Django :8000
npm test
npm run build  # production build (empty VITE_API_BASE_URL → same-origin /api)
```

See the repository root [README](../README.md) for architecture, HOS assumptions, and deployment.
